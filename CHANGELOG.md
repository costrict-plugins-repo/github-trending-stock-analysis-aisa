# Changelog

## 1.0.0 (2026-03-30)

Initial release for Claude Plugin Marketplace.

This version provides 6 agent skills and 7 slash commands for stock and crypto analysis via AIsa API. It includes 8-dimension scoring for stocks, 3-dimension scoring for crypto, dividend analysis with safety scores, portfolio management with live P&L, watchlist with price alerts, Hot Scanner for trending assets, and Rumor Scanner for early market signals.
