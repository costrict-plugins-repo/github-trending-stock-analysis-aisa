description: Find trending stocks & crypto right now (Hot Scanner)
---

Run the Hot Scanner to find trending and high-momentum assets using the stock-hot skill.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/stock-hot/scripts/hot_scanner.py" $ARGUMENTS
```

Present the trending stocks, crypto highlights, news-driven movers, and top watchlist picks. The user can pass `--focus stocks`, `--focus crypto`, or `--output json` as arguments.
